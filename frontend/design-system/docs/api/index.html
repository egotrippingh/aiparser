REST API AIRate

Подключите AIRate к своей системе, чтобы создавать проекты, управлять запросами, запускать проверки и получать ответы за выбранные даты.

Получите API-ключ

Откройте меню аккаунта → «Настройки аккаунта» → «REST API» → «Создать ключ». Сохраните его в менеджере секретов вашей интеграции. Полный ключ виден только после выпуска. После замены, отзыва или смены пароля старый ключ перестаёт принимать новые запросы. Уже принятые запросы могут завершиться.

Базовый адрес — https://airate.tech/api/v1/public. Каждый запрос передаёт ключ в заголовке Authorization: Bearer. Ключ даёт доступ к собственным проектам аккаунта, включая платный запуск проверок. Храните ключ на сервере интеграции.

curl -fsS "https://airate.tech/api/v1/public/projects" -H "Authorization: Bearer $AIRATE_API_KEY"

Проекты и запросы

GET /projects возвращает список проектов. GET /projects/{project_id} возвращает настройки, ревизию и список запросов. POST /projects создаёт проект из JSON с обязательными полями name и brand_name. Опциональные поля config, queries и schedule позволяют указать системы, начальные запросы и расписание.

PUT /projects/{project_id} сохраняет проект целиком. Передайте поля name, brand_name, config, schedule, queries и revision из свежего GET с нужными правками. Если у проекта задан device_id, передайте и его. При 409 прочитайте текущую версию, чтобы не затереть параллельные изменения.

GET /projects/{project_id}/queries возвращает запросы с их ID. POST на этот же путь добавляет один запрос. Обязательное поле — text, дополнительные — group_tag (группа) и active (по умолчанию true). DELETE /projects/{project_id}/queries/{query_id} удаляет запрос и возвращает 204. Сохранённые ответы по нему доступны за прежние даты.

curl -fsS "https://airate.tech/api/v1/public/projects" \
  -H "Authorization: Bearer $AIRATE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"Мониторинг бренда","brand_name":"Пример","config":{"services":["chatgpt"]},"queries":[{"text":"Какие сервисы подходят для мониторинга бренда?"}]}'

Рассчитайте стоимость и запустите проверку

GET /projects/{project_id}/quote возвращает число проверок count, верхнюю границу списания total_kopeks и доступный баланс available_kopeks в копейках. Проверки расходуют баланс и бесплатные сканы аккаунта по тем же правилам, что и в кабинете. Баланс проверяется при постановке в очередь, платные средства резервируются по мере обработки.

Для POST /projects/{project_id}/runs передайте revision, provider_state и free_scans_state из расчёта и новый request_id из 32 строчных шестнадцатеричных символов. Повтор с тем же request_id возвращает прежний запуск. При 409 из-за изменения расчёта запросите новый. При конфликте с другим активным запуском дождитесь его завершения.

Ответ на запуск содержит id. GET /projects/{project_id}/runs/{run_id} возвращает состояние и прогресс. Состояния done, failed, cancelled и missed означают окончание запуска. GET /projects/{project_id}/runs возвращает последние запуски, параметр limit принимает от 1 до 100, по умолчанию 50.

POST /projects/{project_id}/runs/{run_id}/command принимает JSON с полем action. Используйте "pause", "resume" или "stop". При остановке дождитесь состояния cancelled, прежде чем снова запускать или удалять проект.

# Python 3. Укажите ID своего проекта. Скрипт отправит платный запуск после подтверждения.
import json, os, uuid
from urllib.request import Request, urlopen

base = "https://airate.tech/api/v1/public/projects/PROJECT_ID"
headers = {"Authorization": "Bearer " + os.environ["AIRATE_API_KEY"],
           "Content-Type": "application/json"}

with urlopen(Request(base + "/quote", headers=headers), timeout=30) as response:
    quote = json.load(response)
print("Проверок:", quote["count"], "Верхняя граница, коп.:", quote["total_kopeks"])
if input("Запустить? [y/N] ").lower() == "y":
    body = {k: quote[k] for k in ("revision", "provider_state", "free_scans_state")}
    body["request_id"] = uuid.uuid4().hex
    print("request_id:", body["request_id"], flush=True)
    request = Request(base + "/runs", json.dumps(body).encode(), headers)
    with urlopen(request, timeout=30) as response:
        print(json.load(response))

Получите сохранённые ответы

GET /projects/{project_id}/answers требует date_from и date_to в формате YYYY-MM-DD. Границы включаются. Для одного дня укажите одинаковые даты. Дата серверной проверки рассчитана в часовом поясе проекта на момент запуска.

В items возвращаются ID результата, запуска и запроса, текст запроса, служба, дата, статус, сохранённый текст answer_text и источники sources. Если текст ответа отсутствует, answer_text равен null. Для фильтра по системе передайте service, например chatgpt. Допустимые системы для новых проектов — google_aio, yandex_neuro, chatgpt, perplexity и gemini.

За один запрос возвращается до limit записей (1–100, по умолчанию 50). Если next_after_id содержит число, передайте его как after_id в следующем запросе с теми же датами и системой. null означает конец списка.

curl -fsS "https://airate.tech/api/v1/public/projects/PROJECT_ID/answers?date_from=2026-11-01&date_to=2026-11-19&limit=50" \
  -H "Authorization: Bearer $AIRATE_API_KEY"

Ошибки API

401 — ключ отсутствует, отозван или недействителен. 402 — недостаточно средств. 404 — объект недоступен по этому ключу или ID. 409 — изменился расчёт либо у проекта уже есть активный запуск. 422 — проверьте поля запроса и настройки проекта. Подробности ошибки передаются в detail.
