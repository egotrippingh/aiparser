# Тёмная дизайн-система AIRate

Десктопный HTML-стенд для согласования. Основа: production `5948bfee2b80402f8243e6aaf19ef45f0b9ffa34`.

1. В рабочем дереве выполните `npm --prefix frontend ci` и `npm --prefix frontend run dev`.
2. Откройте `http://127.0.0.1:5173/design-system/`. Бэкенд для этого стенда не нужен.
3. Для HTML to Figma откройте стенд при ширине 1440 px. Импортируйте его по разделам или целиком. Закрытый диалог можно открыть кнопкой «Открыть пример» перед отдельным захватом.

`src/styles/_tokens.scss` задаёт цвета, типографику, интервалы, радиусы и размеры. Витрина подключает этот модуль через `tokens.scss`. Главная и 404 используют те же SCSS-компоненты, что и витрина. В таблице и графике используются демонстрационные данные.

Градиентные панели предназначены для витрины продукта. Формы и рабочие таблицы используют однотонные поверхности. Основное действие белое. Лавандовый выделяет бренд, фокус и главную серию отчёта. Статус всегда подписан.

Для статического импорта используется текущий WebP-кадр hero. Кнопка воспроизводит исходную десктопную Lottie из приложения. После импорта сверяйте движение в браузере. При работе над главной сохраняйте композицию, движение и тайминги существующей Lottie. Менять можно только акцентные цвета.

Логотип «аирейт»: файл aireyt-wordmark.svg с векторными контурами. Его можно открыть в Figma без установки шрифта.

Десктопная главная для согласования: http://127.0.0.1:5173/design-system/landing/. Разметка в landing/index.html, использует общие токены, утверждённый логотип с кавычками и отдельные цветовые копии исходной Lottie (landing/hero-lavender-*.json). В копиях изменены заливки, обводки, градиенты и цвета вложенных SVG. Геометрия, прозрачность и тайминги сверены с оригиналом. Встроенные растровые знаки сервисов сохранены.

Иконки раздела «Для кого»: Lucide из реестра https://icons0.dev/. Лицензия в landing/LICENSE-lucide.txt.

Главная использует пункты действующей публичной шапки. Раздел #api показывает пример запроса только на чтение и демонстрационный фрагмент JSON. Кнопка копирует команду, запрос не выполняется.

На страницах сайта начинайте секции с заголовка. Декоративные надзаголовки, которые повторяют тему раздела или ссылки, не используем.
Декоративные номера вроде 01, 02, 03 в карточках и шагах не используем.

Макеты следующих экранов: http://127.0.0.1:5173/design-system/login/ и http://127.0.0.1:5173/design-system/404/. Форма в макете не отправляет данные. Рабочие маршруты используют ту же тему, а неизвестные страницы после сборки возвращают HTTP 404 с общим оформлением.
Рабочий предпросмотр кабинета: http://127.0.0.1:5174/design-system/app/report/. Он использует компоненты приложения и тестовую базу. Из корня репозитория запустите `python scripts/frontend_smoke_server.py`, затем из `frontend` выполните `npm run dev -- --config design-system/cabinet-preview.config.ts`. Ссылка на отчёт с порта 5173 открывает этот же предпросмотр.

HTML-макеты справки и юридических страниц доступны по /design-system/docs/, /design-system/terms/ и /design-system/privacy/.
