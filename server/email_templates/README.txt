topup.html and topup.txt are multipart alternatives rendered by server.mailer.
Template variables: amount and balance (formatted from integer kopeks), cabinet_url.
HTML values are escaped; no user-supplied HTML is accepted.

airate.png is a 120x120 transparent raster of the current mark in
frontend/public/assets/brand/airate.svg (viewBox 30x30, fill #ff663f).
Its seven 8x8 squares at (0,0), (11,0), (22,0), (11,11), (22,11), (0,22),
(22,22) are scaled exactly 4x. It is embedded as cid:airate-logo and displayed
at 32x32. No remote image request, SVG support or runtime image library is needed.
