# AI Mentions Tracker

Локальный desktop-парсер упоминаний бренда в ответах ИИ-поисковиков
(ChatGPT, Perplexity, Яндекс Нейро, Алиса AI, Google AI Overview). Работает
целиком на компьютере пользователя, под его собственными залогиненными
сессиями, без сервера и без подписки. Полный план — `../.claude/plans/proud-zooming-comet.md`
(или там, куда его сохранил Claude Code).

## Статус

Работают и подтверждены живыми прогонами четыре адаптера: **Perplexity,
ChatGPT, Алиса AI, Google AI Overview**. Реализовано:

- Схема БД (SQLite) и репозиторий — `app/db/`
- FastAPI-бэкенд: проекты, запросы, сканы (SSE-прогресс + снимок состояния),
  дашборд, настройки — `app/api/`
- Слой браузера на Camoufox: одна вкладка на сервис, персистентные профили,
  видимое окно, человекоподобный тайпинг, зачистка зависших процессов,
  кэш неудачного `geoip` — `app/scanner/`
- Детектор бренда: правила (точное/нечёткое совпадение, домены, маркетплейсы)
  плюс LLM через OpenRouter — `app/detect/`
- Определение статуса входа по cookies профиля — `app/scanner/profiles.py`
- Веб-интерфейс: дашборд с динамикой, запросы, скан с глобальным прогресс-баром,
  настройки — `web/`

Не реализовано: адаптер **Яндекс Нейро** (блок нейроответа в выдаче ya.ru не
показывался ни на одном из проверенных запросов даже с логином — писать было
не по чему), **Gemini**, глубокая проверка страниц-источников
(`deep_check_depth` сохраняется, но логика не написана), экспорт/импорт
проекта и portable-сборка.

## Лимиты бесплатных тарифов — главное ограничение

Живой прогон 28.08.2026 на базе из 100 запросов показал: **бесплатные аккаунты
выдерживают примерно 40 запросов**, после чего сервис перестаёт показывать поле
ввода. Perplexity отдал 44 ответа, ChatGPT — 41, дальше оба молчали до конца
прогона. Через три дня квота сбросилась сама, то есть стена временная.

Что из этого следует:

- Программа ловит стену (`ServiceUnavailableError`), прекращает сервис после
  трёх срабатываний подряд и помечает остаток статусом `limit_reached` — это
  «не проверено», а не «не найдено», и в проценте видимости такие запросы не
  участвуют.
- Большая база собирается **дозапуском за несколько заходов**: повторный запуск
  продолжает с места остановки и дописывает результаты в тот же срез, так что
  дашборд видит цельную картину.
- На платных тарифах лимиты кратно выше и база проходит за один прогон.

## Важное расхождение с исходным допущением плана

Perplexity **не всегда** работает анонимно: 28.08.2026 живая проверка
показала, что анонимная сессия иногда упирается в стену логина после
отправки первого же запроса («Зарегистрируйтесь и повторите свой запрос»).
`services.py` помечает это полем `requires_auth` как подсказку для UI, но
кнопка «Войти» в настройках доступна для всех сервисов безусловно — любой из
них может неожиданно потребовать вход, и `ensure_ready()` адаптера это
обнаруживает по факту, а не полагается на статичную метку.

## Установка

```powershell
cd aiparser
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m camoufox fetch   # качает браузер один раз, ~250 МБ
```

Если система под VPN/прокси, у которого схема не выставлена в
`HTTP_PROXY`/`HTTPS_PROXY` (частый случай на Windows — прокси только в
реестре WinINET), выставьте переменные явно перед `pip install` и
`camoufox fetch`:

```powershell
$env:HTTP_PROXY = 'http://127.0.0.1:10809'   # порт вашего VPN-клиента
$env:HTTPS_PROXY = 'http://127.0.0.1:10809'
```

**Важно про версии**: `camoufox` обязательно должен разрешить `playwright<1.61`
— более новый Playwright ломает протокол Juggler патченного Firefox
(`Browser.setDefaultViewport` падает на поле `isMobile`). Это уже закреплено
в `requirements.txt`; если апгрейдите зависимости вручную, следите за этим
ограничением.

## Запуск

```powershell
.\.venv\Scripts\python.exe -m app.main
```

Откроется окно приложения (pywebview + WebView2). Сервер поднимается на
`127.0.0.1:8756` только для этого окна — наружу не торчит.

Для отладки веб-части без окна:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.api:create_app --factory --port 8756
```

и открыть `http://127.0.0.1:8756/` в обычном браузере.

## Тесты

Детектор бренда покрыт юнит-тестами, без браузера, секунды на прогон:

```powershell
.\.venv\Scripts\python.exe tests\test_rules.py
```

## Данные

Portable-режим: всё в `data/` рядом с приложением (БД, профили браузера по
сервисам, скриншоты, debug-дампы HTML при сбое селекторов). Если папка
недоступна на запись (например, установлено в Program Files) — данные уходят
в `%LOCALAPPDATA%\AIParser`. Логика — `app/config.py`.
